# BINART_SEARCH_TREE.CPP
Binary search tree (BST) implementation in python with insertion, deletion, searching, traversal, depth calculation, mirror image, copy creation, parent-child display, leaf nodes, &amp; level-wise Traversal.
# 🌳 Binary Search Tree – Data Structures Practical 4

## 📌 Problem Statement

Implement a Binary Search Tree (BST) and perform the following operations:

- Insert with duplicate entry handling
- Delete a node
- Search an element
- Display tree traversals
- Find depth of the tree
- Display mirror image
- Create a copy of the tree
- Display parent nodes with their children
- Display leaf nodes
- Display tree level-wise

## 🛠️ Technology Used

- Python 3
- Data Structures
- Binary Search Tree
- Recursion
- Queue

## ✨ Features

✅ Duplicate values are handled  
✅ Insertion and deletion  
✅ Searching  
✅ Inorder, Preorder and Postorder traversal  
✅ Tree depth calculation  
✅ Mirror tree  
✅ Deep copy of BST  
✅ Parent-child relationship display  
✅ Leaf node identification  
✅ Level-wise tree display  
✅ Interactive menu-driven program
